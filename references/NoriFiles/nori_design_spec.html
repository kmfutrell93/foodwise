Implementation Notes for Developers
File Format: All assets exported as PNG with transparent background (RGBA). Ready for React Native <Image> or Expo Asset loading.
Recommended Size: Display at 80–120px width on mobile. Use resizeMode="contain".
Animation Tip: For nori_tablet and nori_lightbulb, consider a subtle float CSS/Animated loop (+4px Y, 1.8s ease-in-out infinite) for loading states.
Accessibility: Always include accessibilityLabel per pose. Example: "Nori the owl pointing at next step".
Folder Convention: assets/mascot/nori_[pose].png · assets/mascot/nori_[pose]@2x.png
